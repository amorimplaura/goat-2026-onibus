# GOAT 2026 — Consulta dos Ônibus

Site de consulta dos ônibus do Retiro da Persê.

## Publicação

Ative **Settings → Pages → Deploy from a branch → main → /(root)**.

## Dados

O arquivo `dados.js` contém os 325 participantes. Ele precisa ser enviado para a raiz do repositório. Atualizações não são sincronizadas automaticamente com a planilha.

## Privacidade

O repositório é público e os nomes dos menores ficam acessíveis. A organização deve garantir as autorizações adequadas para publicação.
